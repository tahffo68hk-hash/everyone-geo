验证日期：2026-10-18。环境：Linux，Node 24，DISPLAY `:2`，Playwright Chromium；产品地址 `http://localhost:3100`。

通过 `npm run test:cloud` 实际执行，不访问真实平台、不付费、不公开发布。机器结果见 [cloud-verification.json](cloud-verification.json)，有界面 Chromium 页面截图见 [cloud-headed.png](../screenshots/cloud-headed.png)。截图已由代理图像查看工具实际打开检查；页面截图不等于用户桌面远程控制证据。

## 完整流程验收

`npm run test:e2e` 使用新的应用会话并断言 Provider 为 mock：只填品牌 → 生成并编辑/保存问题 → 检测 → 从保存回答校验提及数量和分母 → 报告 → 证据关联建议 → 小红书、文章、抖音及其他渠道内容生成 → 三类草稿编辑/保存并回读 → 发布页面添加本地账号、选择素材、保存任务 → 页面启动独立执行器 → `FILLED_AWAITING_REVIEW`。

断言 `mode=PREPARE_ONLY`、`is_mock=1`、`url=null`、媒体数量 1、标题回读一致、`finalSubmitClicked=false`。十张主页面截图保存到 `screenshots/`；桌面 1440×1000，移动 390×844。`npm run screenshots` 可重新生成，同样会新增本地 Mock 验收记录。

`npm run test:publish` 额外验证 ZIP 发布包、测试任务不能回填虚假公开 URL、跨会话发布包读取被拒绝。`npm test` 含 16 项指标/Gateway/内容/执行器测试，实际真实模型请求与公开发布均为 0。

## 尚未取得的外部条件

- 全部真实平台均为 **未验证-待用户登录**，具体能力矩阵见 [README](../README.md)。没有任何真实平台通过已登录上传、自动填写和人工接管验收；规格十五 H 未完成。
- DeepSeek、Qwen/DashScope 与通用兼容 Provider 的协议实现和注入式测试存在，但真实 Key/付费调用未验证。
- 用户后续应在可信有桌面环境使用官方登录方式，逐个平台在 PREPARE_ONLY 下验证。若无法接管云桌面，可在本机启动同一仓库和执行器，或下载人工包；不导出真实 Cookie 到聊天。
- 真实账号有效期、风控、页面结构、封面、分类、原创/AI 声明需逐平台验证。不会绕过验证码、账号限制或自动最终提交。
