# 抖音官方 Connector 能力审计报告

> **审计基准日期**：2026-09-15  
> **审计结论**：`RESTRICTED`（代投稿已全面下线；服务端直发需极其严苛的企业白名单资质；图文笔记无服务端 API）  
> **审查依据**：抖音开放平台 (`open.douyin.com`) 官方公告与 API 文档  

---

## 1. 官方开放平台体系核验

| 模块 / 接口 | 官方文档路径 | 当前状态 (2024-2026) | 适用场景 / 约束 |
| :--- | :--- | :--- | :--- |
| **代投稿接口** (`video.create.bind`) | `/api/douyin/video/create/bind` | **已于 2024-07-20 正式下线并收回** | 官方公告明确废弃第三方代创作者投稿能力 |
| **视频直发接口** (`video.create`) | `/api/douyin/video/create` | **极度受限 (`RESTRICTED`)** | 仅开放给特定行业白名单企业，且须通过严苛审核 |

## 2. 关键能力重大变动与官方规则审查

### 2.1 代投稿接口 (`video.create.bind`) 下线历史与现状
- **历史背景**：2024 年前，第三方 SaaS 曾可使用 `video.create.bind` 接口为绑定的创作者账号提交视频，创作者在抖音 App 内确认后发布。
- **官方下线公告**：抖音开放平台于 **2024 年 7 月 20 日** 正式回收并下线该接口。所有存量调用统一返回权限回收错误码。第三方开发者无法再为个人或未强绑定的第三方创作者进行代投稿。

### 2.2 服务端视频直发 (`video.create`) 的严苛准入门槛
对于企业自有账号的服务端直发：
1. **开发者主体资质**：必须为中国大陆企业法人，个体工商户与个人开发者不具备申请权限；
2. **ICP 与网安备案**：提交 ICP 许可证 / ICP 备案证明、公安网安备案编号；
3. **软件著作权证明**：提供具备自主知识产权的软件著作权证书；
4. **人工审核与白名单准入**：需提交详细的产品功能录屏、使用场景说明、企业合作协议，进入字节跳动商务与法务人工多轮白名单审核（平均审核周期 30~60 天）；
5. **频次与配额限制**：初级接入每日调用配额极低（如 10~50 条/日），超额需申请提额审批。

### 2.3 图文内容生态 (Image-Text Note)
- 抖音虽大力推进图文内容发展，但截至 2026 年，官方仅提供了移动端 App SDK 分享能力（唤起抖音 App 剪辑页）。
- **服务端暂无公开的图文批量发布或直发 REST 接口**。

## 3. GeoLens 平台架构落地策略

GeoLens 采取**双轨安全设计**，兼顾高合规企业客户与日常运营团队：

1. **渠道状态标记**：`DOUYIN` 标记为 `RESTRICTED`，授权模式采用 `OAUTH2`。
2. **连接状态流转**：
   - 客户在 GeoLens 内发起抖音授权时，系统验证 client_key / client_secret；
   - 检查企业应用是否已获批 `video.create` 权限；若未获批，连接状态自动置为 `REQUIRES_APP_REVIEW`，并引导管理员前往抖音开放平台完成资质申请。
3. **出站写闸门与 dryRun**：
   - 在开发、测试及默认生产环境下，出站写闸门保持拦截，生成安全 Mock attempt（URL 格式为 `https://mock.geo.local/douyin/${externalId}`）；
   - 只有当 `EXTERNAL_PUBLISHING_ENABLED=true` 且账号为已获批白名单的企业账号时，才激活真实视频上传分片接口 (`/video/upload` + `/video/create`)。
4. **图文备用机制 (`ManualPublishingPackage`)**：
   - 若客户创建的是图文类短视频或图文合集，系统自动生成抖音专属手工发布包，提供适合竖屏 9:16 的素材排版说明与热门 BGM 推荐指引。
