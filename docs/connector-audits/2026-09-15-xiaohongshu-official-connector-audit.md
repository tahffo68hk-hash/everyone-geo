# 小红书官方 Connector 能力审计报告

> **审计基准日期**：2026-09-15  
> **审计结论**：`MANUAL_ONLY`（无官方第三方 SaaS 服务端图文/视频发笔记 API）  
> **审查依据**：小红书开放平台 (`open.xiaohongshu.com`)、小红书移动开放平台 (`opensdk.xiaohongshu.com`) 官方文档与开发者协议  

---

## 1. 官方开放平台体系核验

| 平台模块 | 官方域名 | 服务定位 | 笔记发布能力 |
| :--- | :--- | :--- | :--- |
| **小红书开放平台** (千帆/Ark) | `open.xiaohongshu.com` | 电商商家、店铺管理、订单履约、商品上下架 | **无发笔记能力**（仅限商品/订单/售后 API） |
| **小红书聚光平台 / 蒲公英** | `ad.xiaohongshu.com` / `pgy.xiaohongshu.com` | 广告投放、KOL/KOC 商业合作招募与结算 | **无第三方 SaaS 自动发文 API** |

| **创作者服务平台** | `creator.xiaohongshu.com` | Web 端创作者手工发布、数据分析看板 | **无官方开放 API**（仅供人工操作） |

## 2. 详细能力审查分析

### 2.1 服务端代发笔记 API (Server-to-Server Note Publishing)
- **官方结论**：**不存在任何对第三方 SaaS / ERP 开放的代发图文笔记或代发视频笔记的服务端 REST/GraphQL API**。
- **限制原因**：小红书官方对社区内容原创性与真实“种草”生态执行最严苛的风控策略。所有官方 API 矩阵严格隔离在“电商履约（千帆）”与“广告变现（聚光）”领域，不开放任何代运营发文接口。

### 2.2 移动端 Share SDK (Native Open SDK)
- **工作机制**：需移动端 Native App 引入 iOS / Android SDK，触发 `shareMessage` 唤起手机上已安装的小红书 App，将图片与文案填充至小红书发布编辑器，必须由**真实用户在手机端手工点击最终的“发布”按钮**。
- **SaaS 适配性**：**不适用**。GeoLens 为企业级云端 GEO/SEO 内容营销平台，无权也无法在没有移动端客户端唤醒与用户手工确认的前提下进行服务端无感代发。

### 2.3 逆向工程 / Web Cookie / 模拟登录风险
- **平台态度**：小红书部署了业界顶级的行为验证码、滑块验证、设备指纹风控（WebRTC/Canvas/WebGL 探针）与账号异常标记机制。
- **合规与法律风险**：根据《小红书开放平台开发者协议》及《社区公约》，任何利用逆向 API、网页模拟点击、无头浏览器（Playwright/Puppeteer）、自动化协议发文的行为均属严重违规。一旦被风控识别：
  1. 导致品牌客户官方账号直接被永久封禁或严重降权（限流、笔记搜不到）；
  2. 产生对服务商的知识产权与不正当竞争法律诉讼风险；
  3. 接口随时因风控改版而失效，维护成本不可控。

## 3. GeoLens 平台架构落地策略

GeoLens 坚持**严守官方合规底线，坚决不采用任何非法逆向与模拟登录工具**：

1. **渠道状态标记**：`XIAOHONGSHU` 标记为 `MANUAL_ONLY`。
2. **连接意图登记**：用户可在系统内登记小红书账号信息与主页链接，状态标记为 `READY_FOR_CREDENTIALS` / `CONNECTED`（用于溯源与追踪）。
3. **手工发布包输出 (`ManualPublishingPackage`)**：
   - 严格按照小红书平台规范生成：
     - **标题**：<=20 字符，精炼抓眼；
     - **正文**：排版清晰，支持表情符号与段落留白；
     - **话题标签**：自动生成 `#GEO` `#品牌营销` 等精准话题；
     - **素材清单**：1~9 张高清图片下载地址或短视频下载地址，标明首图与候选顺序；
     - **发布自查清单**：登录 `creator.xiaohongshu.com` 或 App 发布的 5 步指引。
4. **一键复制与导出**：前端提供一键复制标题、一键复制正文、一键打包下载素材，让运营人员在 30 秒内顺畅完成人工发布，零封号风险。
